Vinyl HQ - come metterla online, installarla e tenerla sveglia

A) ONLINE SU GITHUB
1. Su GitHub crea un repository (es. "vinyl-hq") e carica TUTTI i file di questa cartella nella radice:
   index.html, manifest.webmanifest, sw.js, keepalive.txt, le quattro icone .png,
   la cartella supabase/ e la cartella .github/ (con dentro workflows/keepalive.yml).
   Se trascinando la cartella .github non viene presa, creala a mano: "Add file" -> "Create new file",
   come nome scrivi .github/workflows/keepalive.yml e incolla il contenuto del file.
2. Settings -> Pages -> Source "Deploy from a branch" -> branch main, cartella / (root) -> Save.
3. Dopo un minuto l'app e' su https://TUONOME.github.io/vinyl-hq/

B) SUL TELEFONO
4. Aprila dal telefono: la prima volta crea il PIN e salva il codice di recupero.
5. Impostazioni -> "Installa Vinyl HQ sul telefono" (oppure menu del browser -> "Aggiungi a schermata Home").
6. Impostazioni -> Importa backup, per i dati della vecchia Vinyl HQ.

C) I DATI
- Stanno nel browser del telefono, legati all'indirizzo del sito. Quando carichi una versione nuova
  dell'app su GitHub i dati restano. Si perdono solo se cambi indirizzo, cancelli i dati del browser
  o cambi telefono: per questo esporta un backup ogni tanto (l'app te lo ricorda dopo 30 giorni).

D) TENERE SVEGLIO SUPABASE (quando lo collegheremo)
   Il piano Free mette in pausa il progetto dopo 7 giorni senza richieste. L'automazione in
   .github/workflows/keepalive.yml lo chiama ogni 3 giorni e fa un piccolo commit, cosi' GitHub
   non spegne l'automazione (succede dopo 60 giorni senza commit).
7. In Supabase: SQL Editor -> incolla supabase/keepalive.sql -> Run.
8. In Supabase: Settings -> API: copia "Project URL" e la chiave "anon public".
9. Su GitHub: Settings -> Secrets and variables -> Actions -> New repository secret:
   SUPABASE_URL = l'indirizzo del progetto (es. https://abcdefgh.supabase.co)
   SUPABASE_ANON_KEY = la chiave anon
10. Su GitHub: Actions -> "Tieni sveglio Supabase" -> Run workflow, per provarlo. Deve finire verde.
    Finche' i secrets non ci sono, l'automazione parte lo stesso ma non fa nulla: nessun errore.
